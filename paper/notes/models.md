# Stage 8: classification models, LAE case vs control (Design A)

**POST-HOC. Not pre-specified.** `analysis_plan.md` ("Not done") states that no predictive model, classifier or decision tree is fitted. These models were added afterwards at the author's request and must be reported as post-hoc and exploratory.

Generated by `paper/notes/models.py`. Do not edit numbers by hand.

n = 775 QC-passed records (259 cases, 516 controls; prevalence 0.334), one record per patient. Nested CV: outer 5-fold StratifiedGroupKFold by `patient_id` (seed 42), inner 3-fold for hyperparameters and threshold. Median imputation and scaling are fitted inside each training fold. Threshold = Youden J on inner out-of-fold probabilities. AUROC/AUPRC are computed on the pooled outer-fold predictions, with 95% percentile bootstrap CIs (1000 resamples). The fold-mean AUROC ± SD is also shown.

- Set A (29 features): all registered single-value features + age + sex.
- Set B (24 features): set A without p_duration_ms, ptfv1_uv_ms, iab_class, mvp_score, p_axis_deg (the P-derived features; the LAE label was read from these same P waves).
- Age and sex are matching variables (1:2, sex exact, age ±5 y), so they carry almost no signal by design.
- fqrs_present is missing on 290 of 775 records and is median-imputed.
