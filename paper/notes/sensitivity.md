# Sensitivity analyses and one post-hoc check

Run 2026-10-10. Script: `paper/notes/sensitivity.py`. When the script ran,
`analysis_plan.md` had sha256 `fb96c390…ad1b0`, the same file the primary analysis
used. The post-hoc entry was then appended to its Deviations section, which changes
the hash to `1b42876f…612003`. No text above Deviations was edited. The delineator,
feature code, `qc.py` and `config.yaml` were not touched. No predictive model,
classifier or decision tree was fitted.

**Reference: primary result (Design A, `group_comparison.md`).** Adjusted
P-duration difference +2.0 ms (95% CI −0.9 to 5.0), p = 0.17, not significant.
For PTFV1 (a secondary endpoint) the adjusted difference was −3627 µV·ms (−4237 to −3017), q < 0.0001.

## 1. Complete matched sets (pre-specified)

There are 159 sets in which the case and both controls passed QC. For each set,
d = case value − mean of the two control values. The table gives the mean d with a
paired-t 95% CI, and a Wilcoxon signed-rank p. There are no covariates, because the
sets are matched on age and sex. Output: `out/sens1_matched_sets_designA.csv`.

| feature | n sets | mean d (95% CI) | p paired t | p Wilcoxon |
|---|---|---|---|---|
| **p_duration_ms** (primary) | 159 | +2.54 ms (−1.10 to 6.18) | 0.170 | 0.156 |
| ptfv1_uv_ms (secondary) | 159 | −3644 µV·ms (−4487 to −2801) | <0.0001 (q <0.0001) | <0.0001 (q <0.0001) |

The other 22 secondaries, with BH q values for both tests, are in the CSV. For the
secondaries, BH is applied separately to the paired-t p values and to the Wilcoxon
p values (see Deviations).

**Agreement: agrees with the primary result.** P duration is not significant
(p = 0.17), and the PTFV1 estimate is close to the primary analysis's −3627 µV·ms.
